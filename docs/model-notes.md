# 京都工芸繊維大学 松ヶ崎キャンパス v5

`kit_matsugasaki_campus_v5.blend` が東西両地区の全体モデルです。`open_campus.ps1` で同梱Blenderから開けます。
`kit_building_studies_v5.blend` は建物別・校門別の閲覧用シーンを備えます。シーン欄の `Access |` から校門・塔を確認できます。

## 今回の修正

- 大学の2025年キャンパスマスタープラン、バリアフリーマップ、入試配置図、研究室の搬入案内、文化財記録、施工会社の写真へ調査を拡張。
- 中央東門・中央西門はOSMの門ノードへ配置し直し、横断歩道も両門を結ぶ位置へ移動。横長のタイル壁、笠木、ランタン、菱形の門扉を作成。
- 東門は文化財記録の主開口5.4 mを反映。石張り門柱、通用門、別体の五角形の旧門衛所を追加。
- 西門・西北門・馬橋門・中央南門・中央西自転車用門を個別作成。西北門は公式写真に見える曲線状の手すりを追加。
- 大学の塔を中央東門奥の最初の植栽区画へ移し、色帯のある2列の面を西に向ける。白い曲面の側板、横目地、台座を追加。
- 各棟の確認可能な入口は、方位と壁沿いの相対位置を個別指定。南側中央へ自動配置するルールを置換し、北側・東側・西側の入口と複数入口を作成。建物の壁に実際の開口を作り、スロープ・踊り場・手すりを付加。
- 美術工芸資料館の玄関を東、センターホールとプラザKITの主要玄関を北向きに修正。

## 精度

配置図と写真で確かめた「入口のある面・相対位置・外観の特徴」と、推定した「寸法・部材・細かな位置」を分けています。門ノードのある4門はOSM座標を使用。塔の位置は地図と写真の対応から推定し、約5 mの不確かさを見込んでいます。塔の高さ17 mも写真からの推定値です。

入口の座標は公式地図の記号を既存のOSM建物輪郭へ対応させたものです。写真の解像度、図式化、図の年代により誤差があります。スロープの存在を読み取れた場合も、その勾配・長さは測量値ではありません。資料で確認できない小規模棟の入口や背面、屋上機器には前版の推定が残ります。実物を完全再現した測量モデルではありません。

`access-survey.json` に各入口・門・塔の座標、根拠、推定の区分を保存しています。Blender内の `Entrance |` オブジェクトを選んでも根拠を確認できます。`validation.json` はファイル・メッシュ・入口配置の整合性検査で、実測精度の保証ではありません。
