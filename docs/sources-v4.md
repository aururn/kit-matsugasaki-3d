# v4の観察資料と根拠

- [大学公式キャンパスマップ](https://www.kit.ac.jp/uni_index/campus-map/)と[OpenStreetMap](https://www.openstreetmap.org/copyright)：v3から継承した配置。© OpenStreetMap contributors、ODbL 1.0。
- [大学公式オープンキャンパス案内](https://www.kit.ac.jp/ouw-index/)が紹介する[学生制作マップ](https://kitmap.jp)：公開の各施設写真を観察。写真番号と建物名は同じではないため、写っている建物の特徴と案内名を合わせて使用。
- [1号館の写真](https://commons.wikimedia.org/wiki/File:Kyoto_Institute_of_Technology140524NI3.JPG)：Atelier Verde、2014年、CC BY-SA 3.0。ガラスが角に回る階段室、ピロティ、4枚窓、丸い壁の換気口。
- [図書館自身による改修紹介](https://www.libraryfair.jp/poster/2025/230)：2024年春の改修後の入口周りと3階の機能構成。図書館写真 `kitmap-building-7.png` の細いサッシ、窓端の換気部と庇を観察。
- [美術工芸資料館・施設概要](https://www.museum.kit.ac.jp/facility_guide.html)と公開外観写真 `kitmap-building-6.png`：展示ホール、深い入口、上部の張り出した金属枠の窓、側面の細い開口。
- `kitmap-building-11.png`：2号館の入口写真。入口階の上に4段の窓が見えるため、v4では撮影側部分を5階構成に修正。寸法と他の部分の階数は引き続き推定。
- `kitmap-building-10.png`：大学会館の柱廊、タイル階段と水平の色帯。階段や柱廊の正確な位置・寸法は推定。
- `kitmap-building-13.jpg`：東1号館の連続窓、換気口、小さな突出バルコニー、玄関庇と深い軒。東2号館への適用は隣接棟からの推定。
- `kitmap-building-15.jpg`：15号館で確認できる3階部分、上階の細い窓、ルーバー、白い水平庇。14号館の細部は推定。
- `kitmap-building-8.png`：プラザKITの折り曲げた金属スクリーン、コンクリート壁、薄い入口屋根。メッシュの間隔と寸法は推定。
- [岸和郎＋K.ASSOCIATES・KIT HOUSE](https://k-associates.com/works/kit-house/)：4つの屋根採光部、透かし積み、外階段を継承し、押さえ金物と手すりを追加。
- [木村博昭＋ケイズアーキテクツ・60周年記念館](https://www.ks-architects.com/ja/works/p.php?id=89)：白い外装の分割、ガラス下階、庇と屋根。
- [大学・センターホール改修報告](https://www.kit.ac.jp/2025/08/news0805/)と `kitmap-building-4.png`：段状の入口を継承。細かな寸法と隣接部分の構成は未確認。
- [大学公式の和楽庵紹介を含む広報誌](https://www.kit.ac.jp/wp/wp-content/uploads/2021/11/kitnews58.pdf)：木造の和洋折衷建築。v4はv3の形状に木部の接合線と軒部材を追加した段階。

写真ファイルは隣の `kit-campus-v3/references` に観察用として保存。写真を外壁に貼り付けたり、第三者の3Dマップのメッシュを取り込んだりはしていない。権利は各権利者に帰属する。写真を自由利用素材として配布するものではない。

写真未確認の棟については、用途に応じた窓枠・金物・雨水処理などを推定して作成。部品が増えたことと、その建物の実測再現度が上がったことは同義ではない。屋上機器、背面、窓の全数、扉位置、英語の識別用銘板は推定・モデル内表示である。
