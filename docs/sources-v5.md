# v5 調査資料・位置の根拠

調査日：2026-09-10。松ヶ崎の東西両地区を対象とする。

1. **京都工芸繊維大学 キャンパスマスタープラン2025**（大学公式、2026年4月公開）
   https://www.kit.ac.jp/wp/wp-content/uploads/2026/04/cmp2025.pdf
   保存：`references/masterplan-2025.pdf`。印刷p31（PDF33ページ）は2025.4.1のバリアフリーマップ、印刷p42（PDF44ページ）は校門の写真、通行計画、校門配置図。PDF44ページの中央東門写真のキャプションは「西北門」になっているが、写っている塔と周囲の建物、他の公式配置図に照合し中央東門と判断した。計画の着色部分を全て現況の工事完了として扱ってはいない。
2. **キャンパスマスタープラン2014改訂版に収録された2019.4.1バリアフリーマップ**
   https://www.kit.ac.jp/wp/wp-content/uploads/2020/10/cmp2014kaitei.pdf
   保存：`references/barrier-free-2019.pdf`。印刷p72（PDF78ページ）の大判図から入口三角、スロープ、自動扉を観察。2025年の地図と照合。大判の方が記号を読みやすいため、相対位置の読取りに併用。未来の計画記号と既設記号を区別する。
3. **2025年10月の大学院入試建物配置図**（PDF2ページ）
   https://ac.web.kit.ac.jp/02/nyushi/daigakuin/20251001_daigakuin.pdf
   14・15号館側の西向きの出入口、3号館の東向き主玄関、塔と中央門の関係をクロスチェック。試験対象棟だけの入口矢印であり、全棟の出入口一覧ではない。
4. **KIT電磁環境適合性評価研究室 アクセスマップ 2023**（PDF2ページ）
   https://www.cgi-emc.kit.ac.jp/wp-content/uploads/2023/03/KIT-EMC_access-map_20230327.pdf
   8号館105機器搬入口、南側6/8号館接続部、8号館西側玄関の写真と経路、中央西門の受付位置を確認。
5. **文化遺産オンライン：旧京都高等工藝學校 正門及び門衛所**
   https://online.bunka.go.jp/heritages/detail/153575
   主開口5.4 m、左右通用門、石張りのRC門柱、30 m2の五角形門衛所を記録。写真で菱形格子、背の違う門柱、石目地、タイル、庇を確認。登録寸法以外は写真からの概形推定。
6. **岩崎電気：京都工芸繊維大学 松ヶ崎キャンパス グラウンド・テニスコート**（2025年3月施工）
   https://www.eye.co.jp/projects/examples/detail/id/spgr37/cid/6/sid/22/
   `references/central-east-gate-2025.webp`。中央東門の正面写真：横長のタイル壁、石笠木、ランタン、門扉、右側掲示枠、植栽越しの大学の塔の関係を観察。
7. **大学公式 キャンパス＆周辺散策・大学の塔写真**
   https://www.kit.ac.jp/uni_index/principle/campus/
   https://www.kit.ac.jp/wp/wp-content/uploads/2013/06/campus_tou.jpg
   2列の色帯、白い曲面側板、中央縦材、細かな水平目地。高さの実測値は得られていない。
8. **大学公式キャンパスマップ**
   https://www.kit.ac.jp/uni_index/campus-map/
   施設の名称、最新の配置と調査範囲の照合。
9. **OpenStreetMap**
   https://www.openstreetmap.org/copyright
   元データ：隣の `kit-campus-v3/references/osm.xml`。中央東門 node 12491770519、中央西門 node 12506432003、東門 node 1345835370、馬橋門 node 12491770520。原点は経度135.7823、緯度35.0495。建物輪郭はv4から継承。© OpenStreetMap contributors、ODbL 1.0。
